# 📸 Instagram 3-Hour Auto Post Scheduler (No API Required)

একটি সম্পূর্ণ ওয়েব-ভিত্তিক ইনস্টাগ্রাম শিডিউলার। কোনো অফিসিয়াল Meta/Instagram API Key বা ডোমেন/পেইড হোস্টিং ছাড়াই সম্পূর্ণ ফ্রিতে চলে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ:
1. **কোনো API Key ছাড়াই কাজ করে:** Facebook Developer একাউন্ট বা পেইড API ছাড়াই সরাসরি ওয়েবসাইট থেকে ইউজারনেম ও পাসওয়ার্ড দিয়ে লগইন করা যায়।
2. **ওয়েব ইন্টারফেস (Web UI):** কোনো টার্মিনাল কমান্ড দেওয়ার প্রয়োজন নেই। মোবাইল বা পিসি ব্রাউজার দিয়েই সব পরিচালনা করা যাবে।
3. **গুগল ড্রাইভ ইন্টিগ্রেশন:** ইমেজ ও ভিডিওর (Reels) সরাসরি গুগল ড্রাইভের পাবলিক শেয়ারেবল লিঙ্ক দিয়ে পোস্ট করা যায়।
4. **স্বয়ংক্রিয় ৩ ঘণ্টার শিডিউলার:** কিউ (Queue)-তে পোস্ট যোগ করে রাখলে প্রতি ৩ ঘণ্টা পর পর স্বয়ংক্রিয়ভাবে ড্রাইভ থেকে ডাউনলোড করে ইনস্টাগ্রামে পাবলিশ হবে।
5. **২৪/৭ ক্লাউড রানিং:** আপনার পিসি বন্ধ থাকলেও Render ক্লাউডে সার্ভিসটি চালু থাকবে এবং UptimeRobot পিংয়ের কারণে কখনো স্লিপ মোডে যাবে না।

২. আপনার পিসিতে এই ফোল্ডারের ভেতর টার্মিনাল খুলে নিচের কমান্ডগুলো চালান:

### ধাপ ২: Render.com-এ ফ্রিতে হোস্ট করুন
১. [Render.com](https://render.com)-এ আপনার GitHub অ্যাকাউন্ট দিয়ে ফ্রি সাইনআপ / লগইন করুন।
২. ড্যাশবোর্ডে গিয়ে **"New +"** বাটনে ক্লিক করে **"Web Service"** সিলেক্ট করুন।
৩. আপনার GitHub রিপোজিটরি `instagram-scheduler` কানেক্ট করুন।
৪. নিচের তথ্যগুলো দিয়ে ফরমটি পূরণ করুন:
   - **Name:** `instagram-scheduler` (বা যেকোনো নাম)
   - **Language / Runtime:** `Python`
   - **Region:** `Frankfurt (EU Central)` বা `Singapore`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --workers 1 --threads 4 --timeout 180`
   - **Instance Type:** `Free`
৫. **Environment Variables** সেকশনে গিয়ে চাইলে যোগ করতে পারেন:
   - `POST_INTERVAL_HOURS` = `3`
   - `SECRET_KEY` = `আপনার_পছন্দমতো_একটি_সিক্রেট_কি`
৬. নিচে **"Deploy Web Service"** বাটনে ক্লিক করুন। 
৭. ৩-৪ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং আপনি একটি ফ্রি লিঙ্ক পাবেন (যেমন: `https://instagram-scheduler-xxxx.onrender.com`)।

### ধাপ ৩: UptimeRobot দিয়ে সার্ভারকে ২৪/৭ চালু রাখুন (যাতে পিসি বন্ধ থাকলেও পোস্ট হয়)
Render-এর ফ্রি সার্ভার ১৫ মিনিট ইনঅ্যাক্টিভ থাকলে ঘুমিয়ে যায়। UptimeRobot প্রতি ৫ মিনিটে আপনার ওয়েবসাইটকে পিং করবে, ফলে সার্ভার কখনো ঘুমাবে না:
১. [UptimeRobot.com](https://uptimerobot.com)-এ একটি ফ্রি অ্যাকাউন্ট খুলুন।
২. **"Add New Monitor"** বাটনে ক্লিক করুন।
৩. সেটিংসগুলো দিন:
   - **Monitor Type:** `HTTP(s)`
   - **Friendly Name:** `Insta Scheduler Keep-Alive`
   - **URL (or IP):** `https://আপনার-অ্যাপ.onrender.com/health`
   - **Monitoring Interval:** `5 minutes`
৪. **"Create Monitor"**-এ ক্লিক করুন। ব্যাস! এখন আপনার সার্ভার ২৪/৭ সচল থাকবে।

### ধাপ ৪: কীভাবে ব্যবহার করবেন?

#### ১. ইনস্টাগ্রাম লগইন:
- আপনার ওয়েবসাইটের ড্যাশবোর্ডে গিয়ে **"লগইন করুন"** বাটনে ক্লিক করুন।
- আপনার ইনস্টাগ্রামের ইউজারনেম ও পাসওয়ার্ড দিন।
- যদি আপনার অ্যাকাউন্টে ২-ফ্যাক্টর (2FA) বা এসএমএস সিকিউরিটি চালু থাকে, তবে স্ক্রিনে ওটিপি বক্স আসবে। সেখানে ফোনের কোডটি দিলেই লগইন সফল হবে।
- একবার লগইন হলে সেশন ডাটাবেজে সেভ থাকবে, বারবার লগইন করতে হবে না।

#### ২. গুগল ড্রাইভ থেকে পোস্ট যোগ করা:
- গুগল ড্রাইভে আপনার ছবি বা ভিডিও আপলোড করুন।
- ফাইলের ওপর রাইট ক্লিক করে **Share > Share** এ যান।
- **General access** অপশনে গিয়ে **"Anyone with the link"** সিলেক্ট করুন এবং লিঙ্কটি কপি করুন।
- ওয়েবসাইটের ড্যাশবোর্ডে এসে:
  - **Google Drive লিঙ্ক:** কপি করা লিঙ্কটি পেস্ট করুন।
  - **টাইটেল / ক্যাপশন:** পোস্টের জন্য যা লিখতে চান।
  - **হ্যাশট্যাগ:** যেমন `#explore #reels #photography` ইত্যাদি।
- **"কিউ-তে যুক্ত করুন"** বাটনে ক্লিক করুন।

#### ৩. অটোমেশন:
- পোস্ট কিউ-তে জমা থাকবে। প্রতি ৩ ঘণ্টা পর পর ব্যাকগ্রাউন্ড বট স্বয়ংক্রিয়ভাবে একটি করে পোস্ট পাবলিশ করবে।
- আপনি চাইলে তৎক্ষণাৎ টেস্ট করার জন্য পোস্টের পাশে থাকা **"Play / এখনই পোস্ট করুন"** বাটনে ক্লিক করতে পারেন।
